# C Runner

**C Runner es un runtime que ejecuta código C sin la necesidad de compilarlo**.

# Uso

Para usar C Runner solo tienes que usar:
```cmd
.\c-runner.exe main.c
```
para ejecutar el script que quieras.

# Créditos
C Runner usa TCC (Tiny C Compiler) que está licenciado bajo la LGPL 2.1.
No hace falta que te preocupes por la licencia, ya está incluida dentro del archivo de "THIRD PARTY.txt".
